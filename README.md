# projeto_final_prog

Biblioteca.

Nesse projeto de programação, nosso objetivo é criar um código relacionado a uma biblioteca, possuindo um bibliotecário, que terá acesso aos dados gerais como o estoque de livros e aluguéis, também haverá clientes, os quais podem fazer aluguéis dos livros disponíveis, além de se cadastrarem.
